Is your phone linear?

One phone, one affine correction. Does it improve measurements beyond the six positions used to fit it?

In what sense linear?

We model the measured acceleration vector m\mathbf mm from a reference a\mathbf aa:

m=Sa+bS∈R3×3,b∈R3.\boxed{\mathbf m=\mathbf S\mathbf a+\mathbf b}\qquad \mathbf S\in\mathbb R^{3\times3},\quad \mathbf b\in\mathbb R^3.m=Sa+b​S∈R3×3,b∈R3.

S\mathbf SS contains dimensionless gains and cross-axis coupling; b\mathbf bb is a constant bias in m s−2\mathrm{m\,s^{-2}}ms−2. This is affine, linear when b=0\mathbf b=\mathbf0b=0, and linear in twelve parameters. No separate noise term is fitted.

[m1]=[Sb0T1][a1].\begin{bmatrix}\mathbf m\\1\end{bmatrix}=\begin{bmatrix}\mathbf S&\mathbf b\\\mathbf0^\mathsf T&1\end{bmatrix}\begin{bmatrix}\mathbf a\\1\end{bmatrix}.[m1​]=[S0T​b1​][a1​].

Which positions, and why?

Unique identification requires rank⁡(X)=4\operatorname{rank}(\mathbf X)=4rank(X)=4. Four affinely independent references suffice; six opposite positions add redundancy. The planar ±X,±Y\pm X,\pm Y±X,±Y subset has rank 3 and cannot identify the Z response. One repeated reference has rank 1. Gravity magnitudes alone cannot determine arbitrary matrix orientation.

Stable samples, frozen choices

Exclude the first/last second, then screen 0.25 s windows by local RMS vector variation. The training-only rule, max⁡(0.05,median+8×1.4826 MAD)\max(0.05,\mathrm{median}+8\times1.4826\,\mathrm{MAD})max(0.05,median+8×1.4826MAD), freezes at 0.05 m s−20.05\,\mathrm{m\,s^{-2}}0.05ms−2. Keep stable intervals of at least 1 s; gaps over 0.1 s break continuity. Masks were visually checked. Retained samples: 80,677 training; 80,474 testing. No target-error filtering is used.

The authors jointly chose full affine coupling over a simpler diagonal model, accepting more parameters and sensitivity to reference alignment. Means give equal weights but hide variation, so raw data and masks are retained. Whole-run holdouts avoid adjacent-row mixing but remain correlated within a session. No choice was retuned using held-out errors.

04 / Limits & responsibility

Use, limits and responsibility

The effective correction is supported for the tested nominal static positions. The measured angle references are accepted as supplied; this validation does not isolate sensor behaviour from alignment effects. No claim of unrestricted accuracy follows from a good static fit.

Where does the model fail?

The shaking run is retained in full. Peak vector magnitude is 119.821 m s−2\mathrm{m\,s^{-2}}ms−2; RMS magnitude deviation from ggg is 29.115 m s−2\mathrm{m\,s^{-2}}ms−2. Without an independent dynamic reference, these are signal statistics—not acceleration errors, clipping evidence or proof of non-affine response.

Figure 3 · Real changing specific force invalidates gravity-only tilt interpretation. Pixel-bin envelopes retain extremes.

What the demonstration establishes

The same exported calibration corrects fresh acceleration on shared timestamps and scales. Synthetic preview is labelled; reference comparisons require an independent target and still-phone confirmation. A 3D display hold is an intentional safeguard, not a measured sensor failure.

What remains unresolved

Four distinct height settings now extend angle coverage, with one run each and nominal camera-supported 0°. Static repeats remain within-session. Ruler precision, case/rate consistency and physical rehearsal remain to document. A referenced drift or controlled-input experiment is needed for an affine-failure claim.

Both authors retain negative results. Any tuning from these validation errors requires fresh held-out data for a new performance claim.
