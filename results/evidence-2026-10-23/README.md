## Linearity (homogeneity) test

Six-position model pinned only at a_j = +/-g on each axis; it predicts every intermediate input k*g by proportional scaling. Check |a_hat| = g at held-out still orientations (no angle reference needed). Across 11 intermediate orientations (input fractions 0.19–0.98 of g per axis), RMSE 0.0238 m/s², maximum |error| 0.0385 m/s² (0.39 % of g). Raw: 0.0841; full affine: 0.0592 (mean -0.0588). Bounds any departure from proportional scaling (and unmodelled cross-axis coupling) within |a_j| <= g on the gravity sphere; inputs above 1 g are untested.
